PrésentationOverview

GitHub (github.com ou GitHub Enterprise) dans l'éditeur, en onglet du panneau Git. Le plugin fonctionne avec ou sans le plugin Git. Le dépôt est celui du remote origin.

GitHub (github.com or GitHub Enterprise) in the editor, as a tab of the Git panel. The plugin works with or without the Git plugin. The repository is the one of the origin remote.

Pull requestsPull requests

  • Les pull requests ouvertes, fusionnées ou fermées ; en créer une, en brouillon ou non, depuis la branche courante.The open, merged or closed pull requests; make one, draft or not, from the branch checked out.
  • En lire une : description, fichiers et leurs diffs dans un onglet, commentaires et relectures (commenter, répondre sur des lignes), vérifications.Read one: its description, its files and their diffs in a tab, its comments and reviews (comment, answer on lines), its checks.
  • Approuver ou demander des changements, fusionner (merge ou squash, en supprimant la branche si vous le cochez), fermer, rouvrir. GitHub ne permet pas de supprimer une pull request.Approve or request changes, merge (merge or squash, deleting the branch when you tick it), close, reopen. GitHub does not delete pull requests.
  • La fusion porte sur le commit que vous avez vu : si la branche a bougé depuis, GitHub la refuse.Merging asks for the commit you saw: if the branch moved since, GitHub refuses.

Actions et étiquettesActions and tags

  • Les dernières exécutions, leurs jobs et journaux ; lancer un workflow à la main ; relancer les jobs en échec ou un seul job, annuler ou supprimer une exécution.The latest runs, their jobs and logs; start a workflow by hand; rerun failed jobs or a single job, cancel or delete a run.
  • Étiquettes : les lister, en créer (annotées, avec un message), les supprimer.Tags: list, create (annotated with a message), delete.

ConnexionSigning in

  • Pour chaque serveur, le panneau demande un jeton d'accès personnel (un jeton « classic » avec les droits repo et workflow).For each server the panel asks for a personal access token (a classic token with the repo and workflow scopes).
  • Il est gardé dans le trousseau du système (ou, à défaut, dans un fichier lisible par vous seul) et n'est envoyé qu'au serveur pour lequel vous l'avez saisi, en HTTPS.It is kept in the system keychain (or a file only you can read when there is none) and sent only to the server you typed it for, over HTTPS.

Installer et réglerInstall and configure

Ouvrez Fichier › Préférences… › Plugins, cherchez « GitHub » et cliquez sur Installer.

Open File › Preferences… › Plugins, search for “GitHub” and click Install.

PrérequisRequirements

  • git sur la machine et Ardoise 2.8 ou plus récent.git on the machine and Ardoise 2.8 or later.

RéglagesSettings

La page de réglages du plugin, dans les Préférences, concerne les serveurs connectés.

The settings page of the plugin, in the Preferences, is about the servers signed in to.
