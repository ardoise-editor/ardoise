Write a pluginCréer un plugin

Ardoise Editor is a plain editor; plugins add the rest. Anyone can write one, in any language, and anyone can install it from Preferences › Plugins. Ardoise Editor est un éditeur simple ; les plugins ajoutent le reste. Tout le monde peut en écrire un, dans n'importe quel langage, et tout le monde peut l'installer depuis Préférences › Plugins.

What a plugin isCe qu'est un plugin

A plugin is a folder with a plugin.json and a program. The editor starts the program and talks to it over its standard input and output with JSON-RPC 2.0, as language servers do. A plugin can add:

Un plugin est un dossier avec un plugin.json et un programme. L'éditeur lance le programme et lui parle par son entrée et sa sortie standard en JSON-RPC 2.0, comme le font les serveurs de langage. Un plugin peut ajouter :

  • commands, found in the search for actions (Ctrl/Cmd+Shift+A);
  • panels, in the sidebar or under the editor, with a button in the activity bar;
  • items of the status bar, which run a command when clicked;
  • and follow the files opened, saved and closed.
  • des commandes, trouvées dans la recherche d'actions (Ctrl/Cmd+Maj+A) ;
  • des panneaux, dans la barre latérale ou sous l'éditeur, avec un bouton dans la barre d'activité ;
  • des éléments de la barre d'état, qui lancent une commande au clic ;
  • et suivre les fichiers ouverts, enregistrés et fermés.

A panel is described, not drawn: the plugin sends a tree of nodes (columns, texts, buttons, fields, lists, trees…) and the editor draws it with its own widgets, in its theme. What the user does there comes back to the plugin as events.

Un panneau est décrit, pas dessiné : le plugin envoie un arbre de nœuds (colonnes, textes, boutons, champs, listes, arbres…) et l'éditeur le dessine avec ses propres widgets, dans son thème. Ce que l'utilisateur y fait revient au plugin sous forme d'événements.

Start from the templatePartir du modèle

plugin-template is a plugin written in Rust with the SDK: a command and a panel, its tests, and the workflow that publishes its releases. Click Use this template on GitHub, then set id, name and repository in plugin.json.

plugin-template est un plugin écrit en Rust avec le SDK : une commande et un panneau, ses tests, et le workflow qui publie ses releases. Cliquez sur Use this template sur GitHub, puis renseignez id, name et repository dans plugin.json.

use ardoise_plugin::protocol::{Context, UiEvent};
use ardoise_plugin::ui::*;
use ardoise_plugin::{run, Host, Plugin};

#[derive(Default)]
struct Hello { name: String }

impl Plugin for Hello {
    fn command(&mut self, host: &Host, command: &str, _: &Context) {
        if command == "hello.greet" {
            host.notify("Hello from a plugin!");
        }
    }
    fn panel_opened(&mut self, host: &Host, panel: &str) {
        host.render(panel, column([
            text("Hello").style(TextStyle::Heading),
            input("name", &self.name, "Your name").on_submit("greet"),
            button("Say hello", "greet").button_style(ButtonStyle::Primary),
        ]));
    }
    fn ui_event(&mut self, host: &Host, event: &UiEvent) {
        match event.action.as_str() {
            "name" => self.name = event.text().unwrap_or_default().to_string(),
            "greet" => host.notify(format!("Hello, {}!", self.name)),
            _ => {}
        }
    }
}

fn main() -> std::io::Result<()> {
    run(Hello::default())
}
The standard output belongs to the protocol: print with eprintln! (it goes to the plugin's log), never println!. La sortie standard appartient au protocole : affichez avec eprintln! (cela va dans le journal du plugin), jamais println!.

The protocolLe protocole

Each message is a JSON-RPC 2.0 object preceded by a header and an empty line, as in LSP:

Chaque message est un objet JSON-RPC 2.0 précédé d'un en-tête et d'une ligne vide, comme en LSP :

Content-Length: 52\r\n
\r\n
{"jsonrpc":"2.0","method":"ui/event","params":{...}}

The editor sends initialize first and waits for its answer; it sends shutdown last, then closes the input (and stops the program 2 seconds later if it is still there). A plugin that stops by itself is shown as stopped, with a button to start it again.

L'éditeur envoie d'abord initialize et attend sa réponse ; il envoie shutdown en dernier, puis ferme l'entrée (et arrête le programme 2 secondes plus tard s'il est toujours là). Un plugin qui s'arrête de lui-même est montré comme arrêté, avec un bouton pour le relancer.

Other languagesAutres langages

Anything that reads its input and writes its output will do. In Python, with "command": ["python3", "main.py"]:

Tout ce qui lit son entrée et écrit sa sortie convient. En Python, avec "command": ["python3", "main.py"] :

import json, sys

def read():
    length = None
    while True:
        line = sys.stdin.buffer.readline()
        if not line:
            return None
        line = line.strip()
        if not line and length is not None:
            break
        if line.lower().startswith(b"content-length:"):
            length = int(line.split(b":")[1])
    return json.loads(sys.stdin.buffer.read(length))

def send(message):
    body = json.dumps({"jsonrpc": "2.0", **message}).encode()
    sys.stdout.buffer.write(b"Content-Length: %d\r\n\r\n" % len(body) + body)
    sys.stdout.buffer.flush()

while (message := read()) is not None:
    method = message.get("method")
    if method in ("initialize", "shutdown"):
        send({"id": message["id"], "result": None})
        if method == "shutdown":
            break
    elif method == "command" and message["params"]["command"] == "hello.greet":
        send({"method": "window/notify", "params": {"message": "Hello from Python!"}})
    elif method == "panel/opened":
        send({"method": "ui/render", "params": {

What the plugin writes to its standard error is in plugin.log, in its data folder (also given as data_dir and in ARDOISE_PLUGIN_DATA): ~/.local/share/ardoise/plugin-data/<id>/ on Linux, ~/Library/Application Support/ardoise/plugin-data/<id>/ on macOS. L'éditeur installe la dernière release d'un dépôt GitHub. Elle doit contenir :

  • SHA256SUMS, tel que sha256sum l'écrit : l'éditeur vérifie l'archive avec.

The template's Release workflow does all this when a tag vX.Y.Z is pushed. People then install the plugin from Preferences › Plugins by typing owner/name: the editor shows its name, author, what it adds, and warns that it runs with their rights before installing it. Check for updates finds newer releases.

Le workflow Release du modèle fait tout cela quand un tag vX.Y.Z est poussé. Official pluginsPlugins officiels

The official plugins are listed in ardoise-editor/plugins. Their ids start with ardoise., their repositories are in the ardoise-editor organization, and their SHA256SUMS is signed (SHA256SUMS.sig3) with the key of Ardoise Editor's own releases: the editor refuses an official plugin whose signature is wrong.

Les plugins officiels sont listés dans ardoise-editor/plugins. Leurs identifiants commencent par ardoise., leurs dépôts sont dans l'organisation ardoise-editor, et leur SHA256SUMS est signé (SHA256SUMS.sig3) avec la clé des releases de Ardoise Editor : l'éditeur refuse un plugin officiel dont la signature est fausse.
